# NexusFlow Frontend

Frontend application for the NexusFlow Visual IoT Telemetry & Rule Engine.

The frontend provides a visual workflow editor, telemetry dashboards, device monitoring, and real-time alert visualization.

---

## Features

### Workflow Builder
- Drag-and-drop editor
- React Flow integration
- Custom nodes
- Node configuration panels
- Workflow validation
- Save workflows

### Dashboard
- Live telemetry
- Device overview
- Active workflows
- Alert statistics

### Monitoring
- Device management
- Telemetry history
- Alert history

### Real-Time Updates
- WebSocket integration
- Live sensor values
- Live alerts

---

## Tech Stack

- React
- React Flow
- Socket.IO Client
- Axios
- Recharts / Chart.js
